## ✨ Features

### 🎯 Core Features
- **Three Operating Modes**: Basic, Scientific, and Programmer
- **Memory Functions**: Store, Recall, and Clear memory
- **History Display**: Shows previous calculations
- **Keyboard Support**: Full keyboard navigation
- **Responsive Design**: Works on desktop and mobile devices
- **Smooth Animations**: Modern UI with hover and click effects
- **Error Handling**: Graceful error management with visual feedback

- Large, easy-to-read display
- Expression preview
- Calculation history
- Memory indicator

## 🎯 Modes

### 1️⃣ Basic Mode
Standard calculator operations:
- Addition (`+`)
- Subtraction (`−`)
- Multiplication (`×`)
- Division (`÷`)
- Decimal operations
- Sign toggle (`±`)

### 2️⃣ Scientific Mode
Advanced mathematical functions:

#### 📐 Trigonometric Functions
- `sin`, `cos`, `tan`
- `sin⁻¹`, `cos⁻¹`, `tan⁻¹` (inverse)

#### 📊 Logarithmic Functions
- `log` (base 10)
- `ln` (natural log)

#### ⚡ Exponential Functions
- `xʸ` (power)
- `10ˣ` (10 to the power)
- `eˣ` (exponential)

#### 🌱 Root Functions
- `√` (square root)
- `∛` (cube root)

#### 🔢 Other Functions
- `x!` (factorial)
- `1/x` (reciprocal)
- `π` (pi constant)
- `e` (Euler's number)

### 3️⃣ Programmer Mode
Bitwise operations and number base conversions:

#### 🔄 Base Conversion
- `BIN` (Binary)
- `OCT` (Octal)
- `DEC` (Decimal)
- `HEX` (Hexadecimal)

#### ⚙️ Bitwise Operations
- `AND`
- `OR`
- `XOR`
- `NOT`
- `Shift Left (<<)`
- `Shift Right (>>)`

#### 🔤 Hexadecimal Support
- A, B, C, D, E, F digits
